Findings
------------------------------------------------------------------------------------------------
  - Best speedup     : M=N=4096  (64, 256)  -> 1.01x  (67.8us -> 67.3us)
  - Worst (regression): M=N=8192  (64, 64)  -> 1.00x  (400.8us -> 401.5us)

  - Wins (>=1.10x)        : 0 configs
  - Neutral (0.95-1.10x)  : 18 configs
  - Regressions (<=0.95x) : 0 configs

Recommendations for follow-up experiments / ncu drill-down
------------------------------------------------------------------------------------------------
  At M=N=8192, recommended ncu configs:
    win    : ( 64, 256)  speedup 1.01x
    regr   : ( 64,  64)  speedup 1.00x
    neutral: (128, 128)  speedup 1.00x

  vs cat_trunc_2d: this kernel has only one input (a 1-D row)
  rather than two 2-D fp32 tiles. The pre-pass register footprint
  for the broadcast result is M*N fp32 (vs cat's 2*M*N fp32), so
  the spill cliff should sit at a wider tile here. Compare the
  speedup matrix against cat_trunc_2d/nsys_results_2d.txt.
